Understanding API Status Codes 

API status codes are numbers returned by a server to explain the result of a request.

Common API Status Codes 200 – OK 

The request was successful.

Example: Successfully retrieving a user's profile.

201 – Created 

A new resource was successfully created.

Example: Registering a new user.

400 – Bad Request 

The server could not process the request because the information sent was invalid or incorrect.

401 – Unauthorized 

Authentication is required or the supplied credentials are invalid.

404 – Not Found 

The requested resource could not be found.

Example: Requesting a user profile that does not exist.

500 – Internal Server Error 

The server encountered an unexpected problem while processing the request.

Summary 200: Request successful. 201: Resource created. 400: Bad request. 401: Authentication required or invalid. 404: Resource not found. 500: Internal server error.
