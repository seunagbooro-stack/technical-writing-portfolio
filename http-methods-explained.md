Understanding HTTP Methods 

HTTP methods tell a server what action a client wants to perform when communicating with an API.

1. GET 

GET retrieves information from a server.

Example: Retrieving a user's profile.

2. POST 

POST sends information to a server, often to create a new resource.

Example: Creating a new user account.

3. PUT 

PUT updates or replaces an existing resource.

Example: Updating a user's account information.

4. PATCH 

PATCH makes partial changes to an existing resource.

Example: Changing only a user's email address.

5. DELETE 

DELETE requests the removal of a resource.

Example: Deleting a user account.

Summary GET: Retrieve information. POST: Create or submit information. PUT: Replace or update information. PATCH: Partially update information. DELETE: Remove information.
